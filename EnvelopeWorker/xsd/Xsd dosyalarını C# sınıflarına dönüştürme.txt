Bu döküman Universal Business Language (UBL) xsd şemalarının C# sınıflarına nasıl dönüştürüldüğünü anlatır.

1. e-FaturaPaketi.zip ve UBL-TR1.2.1_Paketi.zip dosyaları GİB'in websitesinden indirilir.
https://ebelge.gib.gov.tr/dosyalar/kilavuzlar/e-FaturaPaketi.zip
https://ebelge.gib.gov.tr/dosyalar/kilavuzlar/UBL-TR1.2.1_Paketi.zip

2. e-FaturaPaketi.zip dosyasından xsd klasörü çıkartılır.
e-FaturaPaketi.zip\e-FaturaPaketi\xsd

3. UBL-TR1.2.1_Paketi.zip\UBLTR_1.2.1_Paketi\xsdrt\maindoc içindeki dosyalar çıkardığımız xsd klasörü altındaki Envelope klasörüne atılır.
UBL-TR1.2.1_Paketi.zip\UBLTR_1.2.1_Paketi\xsdrt\common klasörü de xsd klasörü altına atılır.

4. xsd klasörünün olduğu konumda xsd komutunun çalıştırılabildiği bir terminal açılır.
örneğin: Developer Command Prompt for VS 2022

5. Terminalde xsd/Envelope klasörüne geçilerek aşağıdaki komut çalıştırılır.

  /out:../

6. Komut başarılı bir şekilde çalışırsa xsd klasörü altında NewUserList.cs adında bir dosya oluşacaktır. (Komuttaki son xsd dosyasının adı NewUserList olduğu için)
Dosyanın içinde komutta adı geçen tüm xsd şemalarının C# sınıflarına dönüştürülmüş hali bulunmaktadır.

7. Şema validasyonu yaparken hata almamak için UBL-xmldsig-core-schema-2.1.xsd dosyasındaki DOCTYPE schema yorum satırı yapılmalıdır.

<!--DOCTYPE schema
 [
   <!ATTLIST schema 
     xmlns:ds CDATA #FIXED "http://www.w3.org/2000/09/xmldsig#">
   <!ENTITY dsig 'http://www.w3.org/2000/09/xmldsig#'>
   <!ENTITY % p ''>
   <!ENTITY % s ''>
  ]-->

8. Schematron hatası almamak için oluşturduğumuz sınıflar arasında bulunan StandardBusinessDocument sınıfına aşağıdaki schemaLocation özniteliği eklenmelidir.

[XmlAttribute("schemaLocation", Namespace = "http://www.w3.org/2001/XMLSchema-instance")]
public string SchemaLocation { get; set; } = "http://www.unece.org/cefact/namespaces/StandardBusinessDocumentHeader PackageProxy_1_2.xsd";
